# Expo UI Atlas support

Expo UI Atlas is an independent interactive reference for Expo UI, provided by Andrew Bierman through Bierman Collective LLC.

[Email admin@biermancollective.com for help or to report a bug](mailto:admin@biermancollective.com). Include the app version, device and OS version, collection/example name, and steps to reproduce the problem. Screenshots help; remove personal information before posting. No account is required to use the app or contact support.

## Common questions

**Do I need Expo Go or a development server?** No. The App Store/TestFlight build runs independently. Expo Go is used when developing from source.

**Which collections can I explore?** The catalog shows shared controls and direct native components supported on your device. Search, filters and Guide follow the same availability.

**Why does an effect look different on my device?** Native controls follow the operating system. Some effects and variants require newer OS versions. The app leaves native defaults in place unless you explicitly customize them.

**Are experiments saved?** Playground settings and sample inputs stay in memory. Reset restores the example; restarting can discard changes.

**Does it work offline?** The catalog, examples, selected inline reference text, privacy policy, support information and notices work offline. Full official references, external links and remotely referenced media need connectivity.

**Can I contribute?** Public source code and contribution instructions are planned. The repository is currently private. Email support to discuss a contribution or substantial API/architecture change.
