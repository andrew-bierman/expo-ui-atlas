## Common questions

**Do I need Expo Go or a development server?** No. The App Store/TestFlight build runs independently. Expo Go is only used when developing from source.

**Why does a collection say Android only?** Direct Jetpack Compose controls run on Android. iOS includes universal and direct SwiftUI examples; availability notes explain the difference.

**Why does an effect look different on my device?** Native controls follow the operating system. Some effects and component variants require newer OS versions. The app leaves native defaults in place unless you explicitly customize them.

**Are experiments saved?** Playground settings and sample inputs stay in memory. Reset restores the example; restarting can discard changes.

**Does it work offline?** The catalog, examples and bundled reference text work offline. External links and remotely referenced media need connectivity.
